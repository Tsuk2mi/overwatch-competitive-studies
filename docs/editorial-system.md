# 内容与视觉规范

## 品牌

中文：守望先锋竞技学宝典。英文辅助：OVERWATCH COMPETITIVE STUDIES。作者：守望先锋竞技学教父。

## 视觉

- 暖纸白 `#f5f1e9`，深灰 `#292b29`，烧橙 `#b64928`，细线 `#d4cec1`。
- 中文标题用现代宋体，正文用系统无衬线，英文标签与数字用等宽字体。
- 桌面正文 18px / 1.85，手机 17px / 1.9；正文宽度不超过 790px。
- 首页以封面排字、编号课程索引和细线建立节奏。正文以自然段为主体，引用仅强调已有关键表述。
- 无渐变、电竞 HUD、背景截图或大型动画依赖。支持减少动效偏好及打印。

## 信息架构

`/` 首页，`/lessons/` 完整目录，`/lessons/<稳定 slug>/` 独立课程页，`/about/` 关于，`/404.html` 404。

课程页：课次、标题、导语、状态、作者、阅读时间、更新时间、正文、已有核心概念、目录、上下课导航。正文一级标题由模板生成，Markdown 从 `##` 起。`###` 表示概念，`####` 表示嵌套补充。

## 内容状态

`status: published` 必须同时为 `contentState: approved`。未完成课用 `coming-soon` / `draft`，正文留空。已确认完成但尚缺来源时可用 `coming-soon` / `awaiting-source`，页面明确“正文待接入”，不误称课程未定稿。

## 术语

保留竞技社区使用习惯，统一 `Off-angle`、`Killbox`、`Testing Water`、`Pre`、`Poke`、`Spike`、`Brawl`、`Dive`、`Green Light`。首次出现且原文适合时使用中文加英文形式，例如胜利条件（Win Condition）。阵容 Poke 与阶段 Poke 根据正文语境区分。不要仅为术语统一而改写理论。

## 发布纪律

只迁移已确认的正式正文。元数据可以归纳正文已有含义；不得从提纲补齐理论、自动发布工作稿、编造案例或课程。缺失图形不凭空重建。参考作者归属和现有链接保留。
